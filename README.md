# Rejection For Eternity
LLM Assisted Dating Card Game Made With Unity 6000.0

You can download the built game from [here.](https://sessizleylek.itch.io/rejection-for-eternity)

I wanted to make a game where we try to understand how to charm characters in a dating sim by generating sentences on current stats with the help of LLMs. But unfortunately the local LLMs that can be run by average consumer hardware is still not that good.
So I won't try to improve this project further. It'll stay as an absurd jam game.
I'm not satisfied with the performance of current AI models considering their huge costs and I'm so sorry for the wasting of all resources that went into this slop.
